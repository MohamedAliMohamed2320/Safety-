# دليل الصحة والسلامة المهنية

موقع ثابت (HTML + CSS + JavaScript) بدون سيرفر وبدون مكتبات خارجية.

## التشغيل
افتح `index.html` في المتصفح مباشرة. أو ارفع المجلد كله على أي استضافة ملفات ثابتة.

## الملفات
- `index.html`: الهيكل.
- `css/style.css`: التصميم (RTL ومناسب للموبايل).
- `js/app.js`: التنقل والبحث والتفاعل.
- `js/data-glossary.js`: المصطلحات. كل سطر: [التصنيف, English, العربي, ملاحظة].
- `js/data-topics.js`: ملخصات الأبواب والمراجع.
- `js/data-questions.js`: أسئلة المقابلات. كل سطر: [الباب, السؤال EN, السؤال AR, إجابة EN, إجابة AR].
- `js/data-illustrations.js`: الرسومات التوضيحية (SVG) لكل باب + أيقونات الواجهة. الرسمة مربوطة بـ id الباب.

## للإضافة
أضف سطرًا جديدًا في القائمة المناسبة. لباب جديد أضف عنصرًا في data-topics.js بـ id جديد ثم استخدمه في الأسئلة، وأضف رسمة بنفس الـ id في data-illustrations.js.

## الوضع الليلي
زر الشمس/القمر في الأعلى يبدّل بين الفاتح والداكن، والاختيار محفوظ في المتصفح.

## تنبيه
المحتوى تعليمي، والأرقام أمثلة من OSHA الأمريكية. ليس مراجعة للمتطلبات السعودية ولا تعليمات تنفيذ في الموقع.
